[BE] Dashboard Özet ve Filtre Endpoint'i

Method: getTaskinDashboardOzet Tablo / kaynak: taşkın risk, tehlike, ekonomik zarar, tahliye, geçiş yapıları özetleri (db) Tüketici: [FE] Taşkın Yönetimi Dashboard Kabuğu Bağımlılık: [FE] Taşkın Yönetimi Dashboard Kabuğu, [FE] Dashboard Grafikleri, [BE] Harita Katmanları Geo Endpoint'i, [BE] Taşkın Tehlike / Risk / Ekonomik Zarar Sorgu Endpoint'i
İster

Dashboard üst bilgi kartları ve global filtre sonucuna göre özet sayıların getirilmesi; sorgu sonrası tüm dashboard bileşenlerinin aynı filtre bağlamını kullanması.

Kabul kriterleri
  • Filtreler: havza, altHavza, il (çoklu), ilce (çoklu), qDonemi (Q5/Q10/Q50/Q100/Q500/Q1000)
  • İlk açılış varsayılanı: il = Ankara (06)
  • Dönüş KPI: riskAlaniSayisi, tehlikeAlaniSayisi, ekonomikZararSayisi, tahliyeNoktasiSayisi, gecisYapisiSayisi
  • Filtre boş veya «tümü» iken tüm kayıtlar; sorgu sonrası yalnızca filtreye uyan özet
  • Uzun süren sorguda istemciye zaman aşımı bilgisi dönebilir / timeout politikası tanımlı

[BE] Harita Katmanları Geo Endpoint'i

Method: getTaskinHaritaKatmanlari Tablo / kaynak: taşkın risk/tehlike/zarar geo, tesis, tahliye nokta/alan, geçiş yapıları; Taşkın Bilgi Sistemi listeleri Tüketici: [FE] Harita ve Bilgi Kartları Bağımlılık: [FE] Harita ve Bilgi Kartları, [FE] Harita ve Liste İlişkisi, [BE] Dashboard Özet ve Filtre Endpoint'i, [BE] Taşkın Alanı Bilgi Kartı Endpoint'i, [BE] Taşkın Tehlike / Risk / Ekonomik Zarar Sorgu Endpoint'i
İster

Dashboard haritasında açılıp kapanabilen katmanlar için coğrafi verinin (özellik + geometri/özet) filtrelenerek getirilmesi.

Kabul kriterleri
  • Katmanlar: taşkınRiskListesi (ısı haritası), suGecisYapilari, tasKinTehlikeListesi, ekonomikZararListesi, tasKinTesisListesi, tasKinTahliyeNoktalari, tasKinTahliyeAlani

  • Veriler Taşkın Bilgi Sistemi altındaki ilgili listelerden türemeli
  • Dashboard filtreleri (havza, alt havza, il, ilçe, Q) uygulanır; varsayılan il Ankara
  • Taşkın çalışma alanı gösteriminde alana en yakın ilçeye nokta atılır
  • Ankara il filtresi doğru çalışır (mevcut USBS iyileştirmesi)
  • Yanıtta istemci bilgi kartı için görüntülenecek alanlar; id / havzaId gibi teknik id alanları kartta gösterilmeyecek şekilde ayrılabilir
