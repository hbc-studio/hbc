Mockup: Dashboard

[BE] Etoloji Dashboard Harita Endpoint'i

Method: getEtolojiDashboardHarita Tablo: kaynak, tesis, musluk, tesis_kaynak, musluk_tesis Tüketici: [FE] Dashboard
İster

Dashboard haritasında gösterilecek düğümler ve yönlü ilişki çizgileri.

Kabul kriterleri
  • Dönüş: kaynaklar, tesisler, musluklar (id, adi, tip)
  • Dönüş: baglantilar — kaynak → tesis (tesis_kaynak), tesis → musluk (musluk_tesis)
  • Her bağlantıda fromId, toId ve yön bilgisi
  • Liste ekranlarındaki ilişkilerle tutarlı veri
Mockup: Dashboard

[FE] Dashboard

Menü: Kaynaktan Musluğa › Etoloji › Dashboard Veri: [BE] Etoloji Dashboard Harita Endpoint'i
İster

Kaynak, tesis ve muslukların harita üzerinde ilişkileriyle gösterilmesi.

Kabul kriterleri
  • Kaynaklar mavi yuvarlak, tesisler fabrika ikonu, musluklar ev ikonu
  • Kesikli mor oklu çizgiler ikonlar arasında: kaynak → tesis, tesis → musluk
  • Üstte legend (kaynak / tesis / musluk / akış yönü)
  • Etoloji menüsünde ilk sıra Dashboard

Ekranlar örnektir, mevcut temaya uygun şekilde yapılmalıdır.

İster
